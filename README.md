### 2. 마크다운이란?
- 마크다운(Markdown)은 일반 텍스트 기반의 경량 마크업 언어다. <br> 일반 텍스트로 서식이 있는 문서를 작성하는 데 사용되며, 일반 마크업 언어에 비해 문법이 쉽고 간단한 것이 특징이다.

       <td style="text-align:center; background-color: lightyellow;">C2 R1</td>
    </tr>

</html>
